# 2026-08-28 설계 결정

## al-folio 폐기, 수제 Jekyll 채택
al-folio v1은 `_layouts`/`_includes`가 gem 내부에 있어 연구실 구조로 개조 불가.
이중언어 미지원. team-aprl과 같은 수제 Jekyll로 재구축.
trade-off: 테마가 주던 검색·다크모드를 직접 구현해야 함 → 직접 구현함.

## Eleventy 검토 후 기각
계획 리뷰 1라운드에서 "자체 Node 생성기 폐기"가 blocker로 나와 Eleventy 안이 나왔으나,
그 근거는 "로컬 Ruby 없음"이었다. Ruby를 설치해 전제가 깨졌고 2라운드에서 리뷰어 3명이
독립적으로 이를 blocker로 재지적. Jekyll 유지 확정.

## 루트=EN, /ko/=KO (JS 리다이렉트 없음)
루트에서 JS로 언어 감지 후 리다이렉트하는 안은 검색 색인·OG 크롤러·공유 링크를 모두 깬다.
루트를 EN 홈으로 완전히 렌더하고 hreflang으로 KO를 선언하는 방식 채택.
trade-off: KO 사용자가 루트로 들어오면 영어를 먼저 본다 → 헤더 토글로 해결.

## 다크모드 마크 액센트 #0088C0
기본 시안 #00A1DF는 다크모드의 밝은 필드(#E8EEF7) 위에서 2.51:1, 초기값 #3FBFF0은 1.81:1.
시안은 장식이 아니라 판독 요소(L의 발, E의 밴드)라 사라지면 안 됨.
후보 4개의 대비비를 계산해 **최악 케이스가 가장 높은** #0088C0 선택(3.41 / 4.71).
리뷰어 제안(#0A4A78)은 accent/field는 좋지만 accent/배경이 2.02로 최악값이 더 낮아 기각.

## 로고를 SVG로 재현
디자이너 원본이 없고 첨부 이미지는 JPEG로 변환돼 투명도가 손실됨.
픽셀 스캔으로 좌표를 복원하고 렌더 결과를 원본과 대조해 검증(사분면 내부 0.000%).
글자 부분은 흰색이 아니라 **투명 녹아웃**임을 확인 — 이 때문에 인라인 SVG + CSS 변수로
넣어야 다크모드에서 성립한다.
알려진 제약: 우하단 글리프는 사방이 닫힌 프레임이라 E로 또렷하게 읽히지 않음.
