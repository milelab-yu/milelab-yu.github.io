# MILE Lab 로고 사용 규정

## 파일

| 파일 | 용도 |
|---|---|
| `mile-mark.svg` | 기본. 카운터(글자 부분)가 **투명**이라 밝은 배경에서만 쓴다. |
| `mile-mark-onwhite.svg` | 카운터가 불투명 흰색. 사진·색면 위, 인쇄물. |
| `mile-mark-light.svg` | 어두운 배경용(밝은 톤 반전). |
| `mile-mark-mono.svg` | 1색 인쇄용. 시안을 흰색 음각으로 대체. |
| `favicon.svg`, `favicon-32.png`, `favicon-180.png` | 파비콘. **M 글리프 단독** 단순화판. |
| `yu-logo.svg`, `yu-logo-white.svg` | 영남대학교 공식 로고(대학 웹사이트 배포본). |

웹 페이지 안에서는 `_includes/partials/mark.html`을 include 해 **인라인 SVG**로 넣는다.
색이 `var(--mark-field)` / `var(--mark-accent)`에 묶여 있어 라이트·다크 테마와
수동 토글에 자동으로 대응한다. `<img>`로 넣으면 이 대응이 깨진다.

## 색

| 역할 | HEX |
|---|---|
| 필드(네이비) | `#062D60` |
| 액센트(시안) | `#00A1DF` |
| 다크 배경용 필드 | `#E8EEF7` |
| 다크 배경용 액센트 | `#3FBFF0` |

## 규칙

- **클리어스페이스**: 정사각형 1개 폭의 1/2(격자 50단위) 이상 비운다.
- **최소 크기**: 웹 48px, 인쇄 12mm. 그 이하에서는 마크 대신 파비콘(M 단독)을 쓴다.
- **시안은 장식이 아니다.** BL의 시안 발이 없으면 L이 I로 읽히고, BR의 시안 밴드가
  사라지면 흰 슬롯 두 개만 남는다. 1색으로 찍어야 하면 `mile-mark-mono.svg`를 쓴다.
- 마크를 단독으로 노출하지 않고 "MILE Lab" 텍스트와 락업으로 함께 쓴다.
- 로고를 늘리거나(비균등 스케일), 회전하거나, 색을 바꾸지 않는다.

## 알려진 제약

- 네 번째 글리프(우하단)는 사방이 닫힌 프레임이라 **E로 또렷하게 읽히지 않는다.**
  워드마크와 함께 쓸 때만 "MILE"로 읽힌다.
- 이 SVG는 디자이너 벡터 원본이 아니라 제공된 래스터 이미지를 **픽셀 단위로 역설계**해
  좌표를 복원한 것이다(사분면 내부 불일치 0.000%로 검증). 원본 AI/EPS/SVG가 확보되면
  교체하는 것을 권장한다. `_source/`에 역설계에 쓴 원본 이미지가 보관돼 있다.
